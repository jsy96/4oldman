# 颐养通 · 居家养老服务管理平台

为养老服务公司打造的 Web 应用：**管理员 / 服务员 / 顾客（老年人）** 三种角色，手机号即账号，登录后进入各自界面。**移动优先设计**（老年人和服务员以手机使用为主），桌面端自动切换为宽屏布局。

## 更新记录

- **2026-10-19　v1.0.261019-1**　初始版本。三角色登录与界面；顾客预约（冲突智能提醒+空闲时段建议）、账户余额与明细；服务员待办确认/完成/异常上报、订单查询、AI 行程路线（地理排序、天气降速、午餐预留、电瓶车电量预估）、一键电话/短信；管理员人员/项目管理、订单管理（改期/改派/异常处理/取消退款）、多维统计与 CSV 导出、批量月度充值、按完成订单发放酬金。后端冒烟测试 30 项全部通过。

## 功能总览

### 顾客（老年人）
- 查看历史订单（含异常原因）、取消未开始的预约
- 预约下一次服务：选项目 → 选日期时间 → 备注
  - **冲突智能提醒**：若该时段与自己的服务员其他顾客的预约冲突（含前后 30 分钟路程缓冲），弹窗提醒并列出冲突单、推荐当天最近的空闲时段，可一键改约或坚持原时间下单
- 账户余额与每一笔明细（充值/扣款/退款，每笔显示余额变化）；余额可为负（欠费提示）
- 「我的」页显示专属服务员姓名电话，一键拨号/发短信
- 大字号适老化界面

### 服务员
- 工作台：今日订单数 / 明日待确认数 / 本月完成数 / 本月酬金
- **前一天确认**：明日待确认订单逐单或一键全部确认
- 完成服务（自动从顾客账户扣款并记账）、上报异常（顾客不在家/临时取消/身体原因等 6 类）
- 订单查询：未来 7 天 / 今日 / 历史完成单；每单显示顾客姓名、地址、预约时间
- **AI 行程路线**（按日期）：地图显示驻地（🏠）和按地理位置优化后的到访顺序（1、2、3…编号大头针+虚线路径），结合 Open-Meteo 天气预报——雨/雪自动降速并提醒带雨具；逐段估算骑行耗时；自动避开 11:30-12:30 午餐时段；按当日气温预估电瓶车电量消耗（48V20Ah 电池模型，低温加大耗电）并给出补电建议
- 每个订单/顾客卡片上有 📞 拨号 / 💬 短信 按钮（手机浏览器直接拉起拨号盘和短信）

### 管理员
- 人员管理：服务员和顾客的增删改（软删除=停用，保留历史数据）；顾客指派固定服务员（一对多）；**地图选点**设置居住位置（用于路线规划）；重置密码
- 服务项目管理：名称/时长/价格/服务员酬金，停用下架
- 订单管理：多维筛选查询；**代顾客下单**（电话预约场景）；改期、改派其他服务员、标记完成、**取消并自动退款**、恢复确认；每单完整操作日志可追溯
- 异常订单处理：见下方流程
- 统计：按时间范围 × 服务员 × 顾客 × 服务项目交叉筛选；订单量/完成/异常/取消、服务收入、退款、酬金、未发酬金；按服务员/项目/月份分组表；一键导出 CSV（Excel 可直接打开）
- 批量充值：按月给勾选的顾客每人充固定金额（虚拟币），全部入账并留痕
- 酬金发放：选服务员+时间区间 → 预览已完成未发订单明细与合计 → 确认发放；已发放不可重复发放，保留发放历史

### 异常订单处理流程
1. **发现**：服务员上门遇顾客不在家/临时取消等 → 在订单上「上报异常」（选类型+说明）→ 订单转「异常」状态
2. **处理**（管理员在 订单管理 → 筛选「异常」）：
   - **改期**：调整预约时间，订单自动恢复「已确认」（若新时段有冲突会提示）
   - **改派**：转给其他服务员
   - **标记完成**：部分完成等场景按正常价完成并扣款
   - **取消退款**：已扣款的自动原路退回顾客账户，生成退款流水
   - **恢复确认**：联系上顾客后恢复原时间上门
3. **追溯**：以上所有动作均写入订单日志，随时查看

## 计费模型

- 顾客余额为虚拟币（内部以「分」存储）。完成订单时按项目定价扣款，余额可为负（欠费，红色提示管理员充值）；取消已完成订单自动全额退款
- 服务员酬金按项目「酬金」字段在下单时快照到订单；管理员按时间区间对「已完成且未发放」订单批量发放

## 技术栈

- 后端：Python 3.12 + Flask 3 + SQLite（WAL），无外部数据库
- 前端：原生 HTML/JS/CSS（无构建步骤）+ Leaflet 1.9.4（已本地化，无需 CDN）
- 天气：Open-Meteo 免费预报 API（无需 API Key，需外网；离线时路线仍可规划，仅天气显示不可用）
- 地图底图：默认高德瓦片（中国城市），可在 `config.json` 切换 `osm`（海外）

## 快速开始

```bash
# 首次：建虚拟环境并安装依赖（本机统一用 uv，不用系统 python）
uv venv .venv
uv pip install --python .venv/Scripts/python.exe -r requirements.txt

# 启动（或直接双击 run.bat）
.venv/Scripts/python.exe server.py
# 浏览器自动打开 http://127.0.0.1:8000
```

服务器监听 `0.0.0.0:8000`，同一局域网的手机可直接访问 `http://<电脑IP>:8000` 使用拨号/短信功能（请勿暴露到公网）。

## 配置说明（config.json）

- `map.center_*`：地图默认中心与缩放（默认上海人民广场）；`map.tiles`：`gaode`（中国）或 `osm`（海外）。**切换城市时改这三项，并重新给人员选点定位**
- `lunch`：午餐预留时段（默认 11:30-12:30，路线自动避开）
- `speed_kmh`：电瓶车晴天 15 / 雨天 12 / 雪天 10 km/h；`road_factor`：直线距离→实际路系数 1.35
- `battery`：电量模型（48V20Ah=960Wh 基准，气温低于 22℃ 每 1℃ 每公里 +0.7Wh）
- `work_hours`：可预约时段（默认 08:00-17:30）；`conflict_buffer_min`：冲突缓冲 30 分钟

## 已知边界

- 短信/电话使用手机浏览器的 `tel:`/`sms:` 协议拉起系统应用；如需平台代发短信需另接短信网关
- 天气为 Open-Meteo 逐日预报（含今起 7 天）；查询更远未来日期无天气数据
- 行程规划按直线距离×路系数估算，未接入导航路网 API；如需精确路线可后续接高德/Google 路径规划
- 顾客余额允许透支（欠费红色提示），符合「先服务后结算」的实际运营习惯
